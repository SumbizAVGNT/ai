OpenCode

Лучший клиент для этого стека. Если контейнер не создан, включи его командой ниже.

docker compose --profile tools up -d opencode-server

Desktop server: http://localhost:4096
user/pass: opencode/opencode

Claude Code proxy

Экспериментально. Tools часто конфликтуют с llama.cpp grammar, поэтому лучше использовать OpenCode.

docker compose --profile claude up -d claude-code-proxy

Codex

Требует OpenAI account/API key. Helper-контейнер можно включить отдельно.

docker compose --profile tools run --rm codex-runner
